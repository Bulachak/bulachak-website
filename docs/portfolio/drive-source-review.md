## General-audience translation

Remove every “Why FamBot Cares,” “How I would apply this at Quoreka,” recipient name, job title being pursued, pitch assumptions, target-brand URL, and application footer. The reusable narrative is challenge → role → approach → delivered artifact → observed result/limitations. Named clients and organizations can remain when they identify real work and are not former application targets; confidential projects stay anonymized.

The portfolio should distinguish delivered work, live artifacts, prototypes, and research/strategy. Only a few cases justify quantified highlights. Evidence links into old application wrappers are unsuitable for a neutral portfolio even when their case text is useful.

## Philosophy found in this source set

The [PPPP framework](https://drive.google.com/file/d/1ioV-dgqvcmhYj7Jz1wXTLzo4FMccDAoh/view) provides a reusable method: Past (record), Present (actual operating state), Possible (viable options), Practice (repeatable behavior), with Protocol across every stage. Stated outcomes are clarity, coherence, capacity and continuity. Its conviction that values need to be built into systems is directly useful; exaggerated universal claims and application-specific footer should be removed.

The Drive portfolio corpus does not reliably define A4A/P4P/I4I. Use the separately researched founder sources in `brand-source-review.md`: Agents for Athletes, Parafencing 4 Progress, and Immigrant for Immigrant. These are relevance lenses, not claims that historical client work was commissioned by those ventures.
